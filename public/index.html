How do I get my cookie?

With the Cookie-Editor extension (easiest):

  1. Install Cookie-Editor.
  2. Open crunchbase.com in a tab and make sure you are signed in.
  3. Click the Cookie-Editor icon in the toolbar.
  4. Click Export (bottom right) → Export as JSON. It copies to your clipboard.
  5. Paste it in the box above and hit Check search right away.

Without the extension: F12 → Network → reload → click any crunchbase.com request → under Request Headers copy the whole cookie: value.

Your cookie is your login. Keep it private, and never commit it anywhere.
